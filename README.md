A 4 KB chess engine in pure Python: 0x88 board, negamax alpha-beta with iterative deepening to a fixed 50,000-node budget, transposition table, killer moves, MVV-LVA ordering, quiescence with check evasions, and a tapered material + piece-square evaluation. Deterministic: no clock, no unseeded randomness.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
